Ask the user to input a number
ask the user to input an another number
if numbers were valid
    display the sum of those two numbers
else
    display a message saying those values were not valid and repeat the first two steps until they are valid and display the sum


// Exercise 2: Check if a Number is Even or Odd

get a number from the user
if number is not valid, ask for input until it is valid
if the number is valid
    if number % 2 evaluates to 0
        tell the user the number is even
    else
        tell the user the number is odd


    

// Exercise 3: 
Write pseudo code that will perform the following.    

a) Read in 5 separate numbers.
b) Calculate the average of the five numbers.
c) Find the smallest (minimum) and largest (maximum) of the five entered numbers.
d) Write out the results found from steps b and c with a message describing what they are


ask the user for 5 numbers
verify input are numbers
    if any input is not a valid number, let the user know and start the input process again
calculate the average (total value of each number / number of values entered)
create variables to track the minimum and maximum values
find minimum by looping through the numbers
    if first iteration, assign the first number to min value
    else compare the current min value with the current number in the list
        if the current number in the list is less than the current min value, assign that to be the new min value
find maximum by looping through the numbers
    if first iteration, assign the first number to max value
    else compare the current max value with the current number in the list
        if the current number in the list is greater than the current min value, assign that to be the new max value
display to the user the average, min, and max
